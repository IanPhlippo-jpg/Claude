# Eisen - robotarm die deuren van een lopende band neemt

Gevraagd door Ian (2026-11-09): een levensgrote robotarm die een deur met zuignappen van een lopende band afneemt.
Materiaal en maakwijze kies ik zelf; alles uitwerken zoals de afzuiging (model, tekeningen, schema volgens de Europese
normen, bestellijst, bouwschema, firmware, één PDF om af te drukken).

| Onderwerp | Wat we weten | Open |
|---|---|---|
| Taak | deur van een lopende band nemen met zuignappen (vacuüm) en **in alle richtingen** kunnen neerleggen (plat, rechtop, gedraaid) (Ian) | cyclustijd |
| Deur | zware deur tot ±60 kg, ±2115 x 1015 x 54 (massief of EI30) (Ian) | |
| Lopende band | bestaat | hoogte, breedte, stopt de band of loopt hij door |
| Grijper | perslucht aanwezig (Ian). Niet alleen deuren: ook plinten, kleine planken, "noem maar op"; grotere en veel meer zuigopeningen, voor de veiligheid (Ian, 2026-11-09). Keuze: vlakgrijper met schuim en een zelfsluitend ventiel per opening, in zones schakelbaar | |
| Herkennen | de robot moet zelf het stuk vinden en weten hoe hij het pakt (Ian): camera boven de band, de besturing rekent grijppunt, draaiing en zones uit | |
| Snelheid | moet snel kunnen bewegen (Ian): assnelheden zoals een industriële robot (A1 130 °/s, A2/A3 120 °/s, pols 220 tot 300 °/s); de cilinder op de schouder is alleen gewichtscompensatie | |
| Uitzicht en normen | zoals een industriële robot (Ian): EN ISO 10218-1/-2, ISO 9409-1, ISO 13849-1, EN 60204-1, ISO 4414, EN ISO 13855/13857/14120 | |
| Opbouw (mijn keuze) | 6 assen nodig voor alle richtingen: draaivoet, schouder, elleboog, en een pols met 3 assen (of 5 assen met een kantelbare grijper) | |
| Materiaal (mijn keuze) | gelaste staalconstructie uit lasergesneden plaat en kokers, of aluminium profiel: na de maat en het gewicht | |
| Veiligheid | Machinerichtlijn 2006/42/EG en EN ISO 10218-2: hekwerk met deurschakelaar, noodstop, vacuümbewaking | |
| Budget | onderdelen €3.000 tot €12.000 (Ian) | |
| Normen | schema's IEC 81346/61082/60617 zoals EPLAN, tekeningen ISO 5457/7200 | |
