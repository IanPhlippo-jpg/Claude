# qa-logs

Ruwe regressielogs per release (QA 0.5.10, F93/F148/F149: elke claim noemt platform, commit en het ruwe log).
`e2e-out/` staat in `.gitignore`; de logs die een claim in README, docs of TASKS onderbouwen, staan hier als kopie.
De kop van elk log noemt versie, pass, commit (en of de werkboom vuil was), platform, URL en datum.
